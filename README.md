# 🏭 Foundry Quality Intelligence

An AI/ML-based system for predicting and analyzing casting defects in foundry manufacturing.

## 🚧 Project Status

Currently under development.

## 🎯 Objective

The goal of this project is to develop an intelligent quality analysis system that can:

- Predict potential casting defects
- Analyze the factors contributing to defects
- Detect defects from casting images
- Retrieve relevant foundry knowledge using RAG
- Generate AI-powered quality insights
- Provide a voice-based interface for operators

## 🧠 Planned Technologies
